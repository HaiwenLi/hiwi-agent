# Task: 创建响应式布局网页

## 目标
构建一个现代化的响应式卡片布局页面，展示编程知识卡片。

## 要求
1. 在 `src/index.html` 中创建页面结构
2. 在 `src/styles.css` 中完成样式
3. 实现以下功能：
   - **CSS Grid** 响应式卡片网格（自动适配 1/2/3/4 列）
   - **Flexbox** 导航栏 + 卡片内部布局
   - **暗色/亮色模式切换**（通过 CSS 自定义属性和 JS）
   - **媒体查询** 适配移动端（< 480px）、平板（< 768px）、桌面
   - **CSS 动画** 卡片入场动画（交错 fade-in + slide-up）
   - **可访问性** 语义化 HTML、ARIA 标签、focus 样式

## 卡片内容（至少 6 张）
每张卡片包含：图标（emoji）、标题、简短描述、标签列表

## 验收标准
- [ ] 页面在 Chrome/Firefox/Safari 上正常显示
- [ ] 在 375px 宽屏幕上单列布局
- [ ] 在 768px 宽屏幕上两列布局
- [ ] 在 1200px 宽屏幕上四列布局
- [ ] 点击暗色模式切换按钮正常切换
- [ ] 卡片入场动画可见
- [ ] 键盘 Tab 导航可见 focus 指示
- [ ] W3C 验证无明显 HTML 错误
