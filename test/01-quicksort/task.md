# Task: 实现快速排序算法

## 目标
实现一个完整的快速排序算法，支持多种基准（pivot）选择策略。

## 要求
1. 打开 `quicksort.ts`，完成 `quickSort` 函数的实现
2. 支持三种 pivot 策略：`first`（首元素）、`last`（末元素）、`median-of-three`（三数取中）
3. 保证原地排序（in-place），空间复杂度 O(log n)
4. 必须通过 `quicksort.test.ts` 中的所有测试

## 验收标准
- [ ] 空数组输入返回空数组
- [ ] 单元素数组正确返回
- [ ] 已排序数组保持正确
- [ ] 逆序数组正确排序
- [ ] 含重复元素的数组正确排序
- [ ] 三种 pivot 策略均正确工作
- [ ] 大数组（10000 元素）能在 100ms 内完成排序
- [ ] 不修改原数组（不可变排序）
